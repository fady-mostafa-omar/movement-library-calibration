# Analysis protocols

The two protocols below were written and approved before the analyses they describe were run (12 Nov 2026). They are
copied verbatim from the project record and therefore use the internal step codes (A.8–A.13, N1–N5, T1 = hand
movement vs rest, R4M = the frozen artifact registry, "cell 4" = other people's executed movements).

- `PROTOCOL_1_library_size_operating_point_window_ensemble.md`: library size, operating points and AUC, window choice
  on training people, fixed ensemble (paper Sections 2.7, 2.9, 3.4–3.6).
- `PROTOCOL_2_references_specificity_multiplicity_controls_curves.md`: own-calibration references, specificity,
  multiplicity, deep-model eye and frontal controls, calibration curves with windows from 1.0 s (Sections 2.6–2.8,
  2.11, 3.3, 3.5, 3.7). Its amendments are at the top of the file.

The analysts already knew earlier results on the same 15 people when these protocols were written (see the paper's
Limitations and `../ANALYSIS_TIMELINE.md`).
